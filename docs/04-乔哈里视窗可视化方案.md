# 乔哈里视窗可视化方案

## 概念映射

将 Johari Window 的四象限映射到 360° 反馈的**自评 vs. 他评**比较：

| 象限 | 自评 | 他评 | 含义 | 领导力解读 |
|------|------|------|------|-----------|
| **公开区 / Arena** | 高 | 高 | 自评和他评一致认为强 | **优势区**：已经展现并被认可的优势 |
| **盲区 / Blind Spot** | 低 | 高 | 自评低但他评高 | **潜能区**：自己未意识到的潜在优势 |
| **隐藏区 / Façade** | 高 | 低 | 自评高但他评低 | **待发展区**：自视过高但实际表现滞后 |
| **未知区 / Unknown** | 低 | 低 | 自评和他评一致认为弱 | **改进区**：公认的待发展领域 |

> 注：经典乔哈里窗中「盲区」对应自评低/他评高，但在360实践中更常见的解读是「潜能在区域」——不一定是缺点，可能是未被充分认知的优势。需根据实际语境微调象限命名。

## 可视化设计

### 二维散点矩阵

- **横轴**：他评得分（所有他评均值）→ 从左（低）到右（高）
- **纵轴**：自评得分 → 从下（低）到上（高）
- **中心参考线**：常模均值（或中位数）垂直线 + 水平线，划分四象限
- **数据点**：每个维度作为一个点
- **颜色编码**：
  - 🔵 蓝色：公开区/优势
  - 🟢 绿色：盲区/潜能
  - 🟡 黄色：隐藏区/待发展
  - 🔴 红色：未知区/改进
- **交互**：hover 显示维度名称、自评分、他评分、差距

### 差距条形图（辅助视图）

- 横轴：维度
- 纵轴：自评 - 他评分差距
- 正条：自评 > 他评（待发展区倾向）
- 负条：自评 < 他评（潜能区倾向）
- 颜色：正/负不同色

## 阈值定义

### 方案 A：均值中心法（推荐）

- 以**常模均值**为分界线
- 自评 ≥ 常模均值 AND 他评 ≥ 常模均值 → 优势区
- 自评 < 常模均值 AND 他评 ≥ 常模均值 → 潜能区
- 自评 ≥ 常模均值 AND 他评 < 常模均值 → 待发展区
- 自评 < 常模均值 AND 他评 < 常模均值 → 改进区

### 方案 B：效应量法（可选）

- 阈值为差距 ≥ 0.5 SD（Cohen's d 中等效应）
- 优势区：自评、他评均高于常模且差距 ≤ 0.3 SD
- 其他象限同理，引入效应量作为"显著性"门槛

## 技术选型

- **绘图库**：Plotly（交互式散点图，适合网页内嵌）
- **输出**：Plotly 图表导出为 HTML 片段，嵌入最终报告
- **备用**：Matplotlib 出版级静态图（适合打印版报告）
