# 常模构建方案

## 定义

常模（Norm）是以被评估者群体为参照，建立各领导力维度上的统计分布基准。个体报告中的所有比较均基于此常模。

## 统计指标

| 指标 | 说明 | 用途 |
|------|------|------|
| M (Mean) | 群体均值 | 中心趋势基准 |
| SD | 标准差 | 离散程度度量 |
| N | 有效样本数 | 常模可靠性标示 |
| Min / Max | 最小/最大值 | 实际取值区间 |
| P5, P25, P50, P75, P95 | 百分位数 | 个体定位（≤X%的人） |
| Skewness | 偏度 | 分布对称性诊断 |

## 常模类型

### 全量常模（Primary Norm）

- 范围：所有被评估者
- 粒度：每个领导力维度
- 用途：通用的基准参考，个体报告的默认比较基准

### 分组常模（Group Norm）— 可选

- 按部门分组
- 按管理层级分组
- 按区域/ BU 分组
- 要求：组内 N ≥ 5，否则合并到"其他"组

### 评估者类型常模（Rater Norm）— 可选

- 自评常模：所有自评的分布
- 他评常模：所有他评的分布
- 上级/平级/下级子常模（如数据支持）

## 个体常模比较逻辑

对于个体在每个维度上的得分，计算：

1. **Z 分数**：`(个体分 - 常模均值) / 常模标准差`
2. **百分位排名**：个体分在常模分布中所处百分位
3. **差距分数**：自评与他评的均值差异
4. **效应量**：差距分数 / 常模 SD（Cohen's d 风格）

## 输出格式

```csv
dimension, norm_mean, norm_sd, norm_p5, norm_p25, norm_p50, norm_p75, norm_p95, norm_n
决策判断, 3.85, 0.62, 2.80, 3.40, 3.90, 4.30, 4.80, 156
团队激励, 3.72, 0.71, 2.50, 3.20, 3.80, 4.20, 4.70, 156
...
```

另输出 JSON 格式（用于前端可视化）：`norms/norm_full.json`

## 质量控制

- 常模计算前检查每个维度 Cronbach's α ≥ 0.70（内部一致性）
- 群组间比较前检查方差齐性（Levene's test）
- 标注低信度维度（α < 0.60）在报告中给出提示
- 常模数据附上计算日期和数据版本号
