# 群体报告图表规格说明书

> 本文档记录群体画像报告中所有定稿图表的生成参数、数据来源和设计决策，
> 确保跨会话可复现。修改图表前请先更新本文档再修改代码。

---

## 全局共用设定

| 参数 | 值 | 说明 |
|------|-----|------|
| 引擎 | matplotlib 3.10 + seaborn | 出版级静态 PNG |
| DPI | 300 | savefig 分辨率 |
| 保存格式 | box_inches='tight', facecolor='white', edgecolor='none' | 白底无边框 |
| 中文字体 | Microsoft YaHei / SimHei | plt.rcParams['font.sans-serif'] |
| 全局调色板 | ['#4C72B0','#DD8452','#55A868','#C44E52','#8172B3','#937860','#DA8BC3'] | 7 色，用于维度区分 |
| 评价源配色 | 本人=#4C72B0 上级=#DD8452 协同方=#55A868 下级=#C44E52 | 固定映射 |
| 象限配色 | 优势区=#2E8B57 盲区=#DAA520 潜能区=#4169E1 待发展区=#CD5C5C | 乔哈里专用 |
| 阈值(2026-07-23) | 自评=4.40 L3他评=4.30 L4他评=4.40 | 乔哈里分界线 |

### CHART-07/08: fig_5_5_wordcloud_L3/4_h90.png

| 字段 | 内容 |
|------|------|
| 章节 | §5.5 评语词频 |
| 类型 | 词云 (wordcloud 库 v1.9.6) |
| 数据源 | group_profiling_data.json → keywords.*.open_codes |
| L4 合并 | L4_新晋 + L4_非新晋 open_codes 逐标签累加 |
| 生成方式 | generate(重复文本) 而非 generate_from_frequencies |
| 文本生成 | 每词重复 max(2, round(freq/max_freq×18)) 次, 随机打乱 |
| 图幅 | 20 × 10 inches (双 panel: 左优势/右发展) |
| 字体 | C:/Windows/Fonts/msyh.ttc |
| WordCloud 参数 | width=1000, height=800, max_words=500, max_font_size=87, min_font_size=4, prefer_horizontal=0.90, relative_scaling=0.5, margin=0, repeat=True, collocations=False, random_state=42 |
| 词频显示 | 不在词上显示频次数字, 无括号 |
| 配色 | 优势词云=Greens colormap, 发展词云=Oranges colormap |
| 备注 | repeat=True 仅对 generate() 生效, 对 generate_from_frequencies 无效 |
