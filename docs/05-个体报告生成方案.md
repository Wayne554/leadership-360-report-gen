# 个体报告生成方案

## 报告结构

每份个体报告为一个自包含 HTML 文件，包含以下章节：

### 1. 封面页

- 被评估者信息（姓名/职位/部门）— 匿名化选项
- 报告日期
- 报告说明（目的、数据来源、保密声明）

### 2. 概览摘要

- 常模比较总览：各维度自评与他评对比（仪表盘或汇总表格）
- 整体领导力画像：个体 vs. 常模的雷达图

### 3. 乔哈里视窗

- 四象限散点图（每个维度一个点）
- 各个象限的维度列表与简要解读
- 差距条形图作为补充

### 4. 各维度详情

- 每个维度独立卡片/区域
- 自评得分、他评均值±SD、常模均值
- 差距分数（Z-score / 百分位）
- 个性化解读文字（由模板生成）

### 5. 开放式评语

- Coze 智能体处理后的结构化评语
- 按主题归类（优势、待发展、建议）
- 高频关键词提炼（词云或标签）

### 6. 发展性反馈

- 基于 RAGFlow 检索的发展建议
- 推荐的发展行动（阅读、项目实践、培训课程）
- 推荐资源和链接

### 7. 附录

- 常模比较原始数据表
- 术语解释
- 报告免责声明

## 模板技术

- **模板引擎**：Jinja2
- **CSS 框架**：自定义 CSS（无外部依赖，内嵌式）
- **交互图表**：Plotly 导出为独立 HTML 片段（自包含）
- **响应式**: 支持桌面和移动端阅读

## 批量生成流程

```
for each user in users:
  1. 读取个体聚合数据
  2. 读取常模数据
  3. 读取个体评语（已处理）
  4. 调用 RAGFlow 检索发展建议
  5. 渲染 Jinja2 模板
  6. 输出自包含 HTML 至 output/individual/{user_id}/
```

## 报告命名规范

- `output/individual/{user_id}/`
  - `index.html` — 主报告
  - `chart_johari.html` — 乔哈里视窗（Plotly，嵌入）
  - `chart_radar.html` — 雷达图（Plotly，嵌入）
  - 注：最终所有图表嵌入 index.html 成为单文件

## 设计原则

1. **面向被评估者**：叙事语气是"你的发展伙伴"，而不是"HR的评价报告"
2. **数据密度适中**：不过度堆砌统计数字，重点展示"你在哪里"和"下一步去哪"
3. **可视化驱动**：图表优先于表格，解读优先于原始数据
4. **可操作**：每一条发展建议都对应具体可执行的行动
5. **保密友好**：不展现他人姓名、具体评语来源
- `output/individual/{user_id}_report.html`


## 发展行动建议章节（Section 4）

### 新增章节结构（2026-07-20）

个体报告新增第 4 节"发展行动建议"，结构如下：

```
Section 4: 发展行动建议
  ├── 引导语（3种变体自动选择）
  │   - standard / mostly_positive / positive
  ├── "我们建议您首先聚焦在以下3个领导力维度..."
  │
  ├── 维度一：[维度名]
  │    ① [行为化举措1]
  │    ② [行为化举措2]
  │    ...
  │    ⑤ [SMH 章节引用]
  │
  ├── 维度二：[维度名]
  │    （同上结构）
  │
  ├── 维度三：[维度名]
  │    （同上结构）
  │
  └── 结语：综合来源说明
```

### 生成逻辑

1. **维度选取**：欧氏距离 √(自评²+他评²)，排除数智变革，升序取 Bottom 3
2. **引导语选择**：根据该人7维度的象限分布自动判断变体
3. **行为举措**：从预编写的 6 维度 × 5 条库中按维度名取出
4. **数据预计算**：全员 882 人的距离数据预存于 `dimension_distances.json`

### 模板渲染

- 使用 Jinja2 模板循环渲染（`templates/reports/individual_report.html`）
- `chr()` 函数注册为 Jinja2 globals，用于输出中文序号（维度一、①等）
- 无外部 JS/CSS 依赖，保持报告自包含
