# 数据架构与聚合逻辑

## 数据结构概览

### 数据源①：360°测评问卷结果

- **格式**：Excel (.xlsx)
- **内容**：每位被评估者在各领导力维度上的评分
- **预计字段**：
  - 被评估人信息（姓名/ID/部门/层级）
  - 评估者类型（自评/上级/平级/下级）
  - 各维度评分（Likert 量表，通常 1-5 或 1-7）

### 数据源②：开放性评语

- **格式**：Excel (.xlsx)
- **内容**：对被评估者的开放式文字反馈
- **预计字段**：
  - 被评估人信息（姓名/ID）
  - 评语文本
  - 评估者类型（可选）

## 数据清洗规则（预设计）

1. **缺失值处理**：
   - 整行空白评分 → 删除
   - 部分维度缺评分 → 保留有效维度，缺失维度标记为 NaN
2. **异常值检测**：
   - 超出量表范围的值 → 标记为异常，由人工确认
   - 同一评估者对所有人都打极端分 → 标注"评估者偏差"
3. **重复记录**：
   - 同一评估者对同一被评估者的重复提交 → 取最近一次
4. **匿名化**：
   - 评语中的姓名/工号 → 替换为 [同事] 或 [上级]

## 聚合逻辑

### 维度层面

- 每个维度下的题目得分 → 取均值作为该维度分
- 维度分聚合到能力域（如有预定义的能力群组）

### 评估者层面

- 自评：单一样本，不做聚合
- 他评：同一被评估者的所有他评 → 均值 ± SD
- 可选项：按评估者来源（上级/平级/下级）分层聚合

### 常模层面

- 全量常模：所有被评估者在各维度上的均值分布（M, SD, P5, P25, P50, P75, P95）
- 分组常模：按部门/区域/层级等维度分组的子常模
- 样本量要求：单组 ≥ 5 人（少于 5 人合并到最邻近分组）

## 数据管线流程

```
raw/360问卷.xlsx ──→ ① 数据清洗 ──→ processed/clean_scores.csv
raw/评语.xlsx    ──→ ① 数据清洗 ──→ processed/clean_comments.csv
                                     │
                                     ├── ② 聚合 ──→ processed/aggregated_scores.csv
                                     ├── ③ 常模 ──→ norms/norm_full.csv
                                     └── ④ 个体 ──→ output/individual/{user_id}/
```

## 技术实现

- `pandas` 为主要数据操作框架
- `numpy` 和 `scipy.stats` 为统计计算工具
- 聚合脚本按编号顺序命名：`01_clean_data.py` → `02_compute_norms.py`
- 中间结果以 Parquet 格式存储（压缩 + 类型保留），最终输出为 CSV
- `src/aggregation/config.py` 存放所有可配置参数（量表范围、维度映射、分组字段等）
