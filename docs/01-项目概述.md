# 项目概述

## 背景

面向基层管理者的2026年度360°领导力反馈项目。HR/OD部门已完成问卷发放、回收和初步导出，现有两份原始数据文件（评分数据 + 开放式评语）。下一步需要对这些数据进行系统化的聚合、分析、可视化和报告生成。

## 目标

1. **数据聚合与常模构建**：对原始评分数据进行清洗、聚合，计算群体常模
2. **乔哈里视窗可视化**：对每个被评估者，基于常模比较生成自评 vs. 他评的四象限可视化
3. **结构化个人报告**：为每位被评估者生成包含完整反馈信息的 HTML 报告
4. **发展性反馈**：基于 RAGFlow 知识库检索权威发展资源，生成个性化发展建议
5. **Skill 封装**：将整个流程封装为标准化的 Codex Skill，便于集成

## 用户角色

- **项目发起方**：集团组织与人才发展（OD/TD）团队
- **报告受众**：被评估的基层管理者（主要）、其上级/HRBP（次要）
- **实施方**：Codex（分析工程实现）+ 用户（领域知识与设计决策）

## 关键约束

- 报告必须是中文为主、自包含 HTML（无外部 CDN 依赖）
- 所有数据处理必须可复现（scripted pipeline）
- 数据保密性：原始数据不出本机
- 常模需提供分组比较能力（可按部门/区域等）

## 项目里程碑

- **M1: 数据探查** — 读取并理解两份 Excel 的数据结构 → 工作记忆更新、数据字典
- **M2: 常模构建** — 数据清洗、聚合、常模统计计算 → data/norms/ 常模数据
- **M3: 可视化** — 乔哈里视窗生成、常模分布可视化 → Plotly 图表模块
- **M4: 报告生成** — HTML 报告模板开发、批量生成 → output/individual/ 报告
- **M5: RAG 集成** — 发展性反馈的知识检索与注入 → src/rag/ 模块
- **M6: Skill 封装** — 整体流程封装为可复用 Skill → src/skill/ + SKILL.md
