# L3/L4 乔哈里阈值选择分析

> 本文档系统记录 L3（战略执行层，196人）和 L4（基层管理者，882人）两个群体在乔哈里视窗可视化中的阈值选择过程、数据依据和决策理由。作为可追溯、可解释、可审计的过程性沉淀，所有后续阈值变更应以此文档为参照。

## 1. 问题背景

### 1.1 乔哈里视窗的阈值需求

乔哈里视窗散点图以**自评**为横轴、**他评**为纵轴，将 7 个领导力维度绘制在统一坐标系中。四象限划分需要**一对全局阈值**（一个自评阈值、一个他评阈值），而非每个维度独立一套阈值。

### 1.2 两层级面临的不同评分分布

L3（中层管理者）和 L4（基层管理者）虽然共享同样的 Likert 5 点量表和 7 维度体系，但评分分布在两个层级上呈现系统性差异：

| 指标 | L3（196人） | L4（882人） | 差异 |
|------|-----------|-----------|------|
| 他评总体均值 | 4.12 | 4.23 | L3 低 0.11 |
| 他评整体 P50 | ~4.13 | ~4.30 | L3 低 ~0.17 |
| 自评总体均值 | 4.31 | 4.37 | L3 低 0.06 |
| 自评-他评差距 | +0.19 | +0.14 | L3 偏差更大 |

核心发现：**评价者对中层管理者（L3）的期望标准系统性地高于基层管理者（L4）**，导致 L3 的他评评分整体左移。因此 L4 的阈值不能直接复用到 L3。

## 2. 方法论基础

### 2.1 为什么采用中位数（P50）而非均值

选择群体中位数（P50）作为阈值基准，理由如下：

1. **分布适配性**：各维度评分呈左偏分布（天花板效应），均值受右尾压缩，中位数更能反映群体典型水平
2. **切割均衡性**：中位数天然将群体等分（约 50% 高于/低于），使四象限具有等分参照
3. **稳健性**：小样本分组（尤其 L3 仅 196 人）下，中位数比均值对极端值更稳定
4. **离散量表的适配**：Likert 5 点量表上，中位数取整（4.50/4.40/4.30）在语义上比均值（4.38/4.12）更接近自然切割点

### 2.2 L3/L4 共享的自评阈值（4.50）

自评阈值两层级统一为 **4.50**，依据：

- L4 全量自评 pooled P50 = 4.50，6/7 维度自评 P50 >= 4.50
- L3 全量自评 pooled P50 ≈ 4.43，取整到 4.50
- 离散型 Likert 量表上，"符合期望"与"超出期望"的语义分界恰好在 4.50
- 两层级统一简化跨层级比较

### 2.3 象限映射规则

| 象限 | 条件 | 含义 |
|------|------|------|
| 优势区 | 自评 >= Tself 且 他评 >= Tother | 已被认可的优势 |
| 盲区 | 自评 >= Tself 且 他评 < Tother | 自视过高 |
| 潜能区 | 自评 < Tself 且 他评 >= Tother | 未意识到的潜力 |
| 待发展区 | 自评 < Tself 且 他评 < Tother | 公认待发展领域 |

其中 Tself = 4.50（两层级统一），Tother 依层级分别为：

- **L4**: Tother = 4.40
- **L3**: Tother = 4.30

## 3. L4（基层管理者）阈值确定

### 3.1 他评 P50 分布

| 维度 | 他评 P50 | 分布特征 |
|------|---------|---------|
| 战略思维-科学决策 | 4.43 | 接近整体上限，自评-他评偏差大（Cohen d=0.60） |
| 创新引领-持续精进 | 4.19 | 系统性偏弱维度 |
| 全球视野-管理复杂情况 | 4.26 | 系统性偏弱维度 |
| 客户导向-珍视客户 | 4.40 | 集中度最高（SD=0.29），最稳定维度 |
| 数智变革-加强数字应用 | 4.00 | 共识性短板，分布最扁平 |
| 发展组织-带兵打仗 | 4.33 | 平均水平 |
| 追求卓越-高效执行 | 4.35 | 自评-他评偏差大（Cohen d=0.51） |

### 3.2 候选方案对比

| 方案 | 优势区 | 待发展区 | 盲区 | 核心信号 |
|------|--------|---------|------|---------|
| **4.40（选定）** | 25.1% | 30.3% | 31.4% | 战略思维/高效执行盲区信号强 |
| 4.30（备选） | 32.3% | 25.2% | 24.2% | 盲区信号减弱，整体偏积极 |

### 3.3 选择 4.40 的理由

1. **盲区信号是真实的诊断信息**。战略思维（Cohen d=0.60）和高效执行（d=0.51）存在显著的群体性自评-他评偏差。4.40 下 31% 的盲区比率恰当地反映了这一自我认知偏差——这是 360 反馈中最有价值的发现之一，不应被阈值放宽所掩盖。

2. **共识性短板信号在严格阈值下更突出**。数智变革在 4.40 下 53% 待发展区（4.30 下为 49%），强化了发展建议的可信度。

3. **创新引领和全球视野的系统性偏弱被完整保留**。这两个维度在群体层面确实低于其他维度，合理的反馈设计应如实呈现这一信号。

4. **区分力最大化**。4.30 方案下 53.9% 的人在战略思维维度落入优势区，报告区分力被削弱。

**最终决定**：L4 他评阈值 = 4.40（对应决策 DEC-20260720-007）。

> 完整分析见 `output/threshold_analysis_report.md`。

## 4. L3（中层管理者）阈值确定

### 4.1 他评 P50 分布

| 维度 | 他评 P50 | 与 L4 同维度差异 |
|------|---------|-----------------|
| 战略思维-科学决策 | 4.16 | -0.27（差异最大） |
| 创新引领-持续精进 | 4.09 | -0.10 |
| 全球视野-管理复杂情况 | 4.09 | -0.17 |
| 客户导向-珍视客户 | 4.36 | -0.04（差异最小） |
| 数智变革-加强数字应用 | 3.90 | -0.10 |
| 发展组织-带兵打仗 | 4.20 | -0.13 |
| 追求卓越-高效执行 | 4.24 | -0.11 |

L3 所有维度的他评 P50 均低于 L4，其中战略思维差距最大（-0.27）。这证实了**对中层管理者的评价标准更严格**。

### 4.2 候选方案对比

| 方案 | 优势区 | 待发展区 | 盲区 | 核心信号 |
|------|--------|---------|------|---------|
| 4.40（复刻 L4） | 13.0% | 43.1% | 31.6% | 过严：43% 待发展伤害发展动机 |
| **4.30（选定）** | 19.0% | 38.7% | 25.7% | 保留发展信号但不过度负面 |
| 4.20（备选） | ~25% | ~32% | ~22% | 稀释了战略思维的盲区信号 |

### 4.3 选择 4.30 而非 4.20 的论证

#### 4.3.1 为什么不是 4.20

将阈值降至 4.20 虽然进一步降低了待发展区比率，但带来了不可接受的副作用：

| 维度 | 他评 P50 | 4.30 下 | 4.20 下 |
|------|---------|--------|--------|
| 战略思维-科学决策 | 4.16 | 盲区信号保留 | 盲区信号大幅稀释 |
| 创新引领-持续精进 | 4.09 | 47% 待发展，23% 优势/潜能 | ~38% 待发展，~33% 优势/潜能 |
| 全球视野-管理复杂情况 | 4.09 | 53% 待发展，26% 优势/潜能 | ~42% 待发展，~36% 优势/潜能 |

关键发现：

- 创新引领和全球视野的 P50 仅 4.09，即便降到 4.20，仍有约 40% 分布在待发展区——**它们不会因为阈值降至 4.20 就被"解救"出待发展区**
- 但 4.20 显著稀释了战略思维的诊断信号——战略思维的 Cohen d=0.60，是 L3 **最显著的认知偏差维度**
- 4.20 使客户导向的待发展区低于 20%，与其他维度反差过大，可能导致读者质疑阈值设置的公平性

#### 4.3.2 为什么不是 4.25

4.25 是一个折中值，但缺少独立的决策锚点：

- 不具备 4.30（适配 L3 他评 P50 + 0.17 偏移）或 4.20（接近 L3 他评 pooled P50）那样的理论依据
- 与 L4 的 4.40 缺乏清晰的"偏移量对应"关系
- 在 5 分量表上，4.25 不易沟通和记忆

#### 4.3.3 选择 4.30 的正向论证

1. **阈值逻辑跨层级一致**。L4 的 4.40 约等于其群体 he 评 pooled P50（~4.30）+ 0.10；L3 的 4.30 约等于其群体 he 评 pooled P50（~4.13）+ 0.17。两者同为"略高于群体中位数"的严格方案，绝对值差异正确地反映了 L3 群体他评更低的分布特征。

2. **保留有意义的发展信号**。4.30 下 L3 整体待发展区为 38.7%，高于 L4 的 30.3%——这恰恰正确反映了"中层管理者的他评更严格"这一事实。

3. **数智变革的共识性短板判断稳定**。数智变革在 4.30 下 58% 待发展，与 L4 的 53% 趋势一致，不受阈值选择影响。

4. **客户导向的信号符合预期**。客户导向在 4.30 下 34% 优势 + 22% 潜能 = 56% 进入积极象限，20% 待发展区——不过度正面也不过度负面。

**最终决定**：L3 他评阈值 = 4.30（对应决策 DEC-20260722-040）。

> 完整分析见 `output/threshold_analysis_report_l3.md`。

## 5. 两层级并行策略的合理性

### 5.1 不统一为同一阈值的理由

| 方案 | 问题 |
|------|------|
| 统一 4.40 | L3 下 43% 待发展区，过严；削弱被评价者的发展动机 |
| 统一 4.30 | L4 下战略思维等维度的盲区信号从 31% 降至 22%，诊断价值减弱 |

### 5.2 差异化阈值不是设计缺陷，而是诊断信号

不同的阈值反映了**评价者对不同层级管理者的不同期望标准**这一真实现象：

> 对中层管理者（L3），评价者要求更高、打分更严——这是组织文化中有意义的信号，不是需要纠正的测量误差。差异化阈值保留了这一信号，使两个层级的反馈在同一体系下有不同的严格度。

### 5.3 代码实现约定

阈值在代码中通过层级参数动态获取：

```python
# src/report/generate_report.py
JOHARI_THRESHOLD_SELF = 4.50  # 两层级统一

def _get_other_threshold(level: str) -> float:
    """根据层级返回他评阈值。"""
    thresholds = {"L3": 4.30, "L4": 4.40}
    return thresholds.get(level, 4.40)
```

所有象限判定、图表渲染、叙事文本均通过此函数获取阈值，确保一处修改、全局生效。

## 6. 未来变更预判

### 6.1 可能触发阈值调整的场景

- **试读反馈**：如果 L4 报告读者持续反馈"待发展区占比过大，影响发展动机"，可重新评估 4.40 至 4.30
- **新群体加入**：如果后续扩展至 L2（总监层级），需独立分析其评分分布，可能产生新的阈值对
- **年度常模更新**：2027 年度数据加入后，需重新检验两个层级的分布是否偏移

### 6.2 阈值调整的影响范围

| 变更项 | 影响范围 |
|--------|---------|
| 代码修改 | `generate_report.py` 一个常量 + `narrative.py` 一段文字 |
| 数据重算 | `dimension_distances.json` 中 quadrant + preamble_variant 需重算（距离数据不变） |
| 报告再生 | 受影响层级的所有 HTML 报告需批量重生成 |

### 6.3 当前管线中阈值的使用位置

```
src/report/generate_report.py  L46-47           -> 常量定义（或动态函数）
src/report/generate_report.py  L221-452          -> 象限判定 + 图表渲染 + 上下文构建
src/report/narrative.py        L342              -> 乔哈里视窗开篇阈值说明文字
data/processed/dimension_distances.json           -> 预计算的象限 + preamble_variant
   thresholds.other                               -> 存储生成时的阈值（审计追溯）
   persons.{id}.dimensions.{dim}.quadrant          -> 逐维度象限标签
   persons.{id}.preamble_variant                   -> 引导语变体
```

> 注意：`dimension_distances.json` 中每个条目的 quadrant 标签和 preamble_variant 是在距离预计算时根据当时阈值固定的。修改阈值后需要重新运行距离预计算脚本，以使派生数据与最新阈值一致。
