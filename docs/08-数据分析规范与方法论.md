## 3. 数据处理规则

### 3.1 缺失值处理

#### 3.1.1 缺失模式验证结论

通过逐行统计非空条目数验证，共发现三种模式：

| 模式 | 说明 | 判定 |
|------|------|------|
| 全空 | 该评价者对某被评价人未作答任何条目 | 整行缺失，排除 |
| 全满 | 该评价者回答了全部条目 | 整行有效 |
| 部分（固定模式） | 仅协同方：L3填21/28条，L4填18/23条 | 整维度缺失（设计因素） |

**验证结果**：

| 评价源 | L3模式 | L4模式 |
|--------|--------|--------|
| 自己 | 全空 或 28/28 | 全空 或 23/23 |
| 上级 | 全空 或 28/28 | 全空 或 23/23 |
| 下级 | 全空 或 28/28 | 全空 或 23/23 |
| 协同方 | 全空 或 **21/28** | 全空 或 **18/23** |

#### 3.1.2 协同方特殊规则

**协同方不评价的维度（两个Level一致）**：

- 数智变革-加强数字应用
- 发展组织-带兵打仗

原因：跨部门协作方难以观察到被评价人在数字化投入和团队管理方面的表现。此属于问卷设计因素，非随机缺失，**不进行插补**。

#### 3.1.3 维度聚合规则

- 同一维度下**至少1个条目有评分**即纳入计算
- 维度得分 = 该维度所有条目得分的**简单均值**
- 维度内所有条目均空则该维度为 NaN

> 理由：用户确认缺失模式是整行/整维度缺失，不存在单条目随机缺失。即有分即代表该评价者对该维度的完整评分。

### 3.2 评价来源转换（多行→1人1行）

#### 3.2.1 转换流程

```
输入：多行（每个评价者一行）→ 维度聚合 → 按评价源分组 → 输出宽表
```

**细步骤**：

1. 遍历原始每行数据，计算被评价人在每个维度上的条目均值
2. 按「被评价人工号」分组，组内按「关系」拆分为：本人、上级、协同方、下级
3. 对每个评价源：取该源下所有行的维度均值，如有多行则再做一次组内平均
4. 输出：1人1行，每列按「评价源-维度名」命名

#### 3.2.2 评价源输出顺序

```
本人 → 上级 → 协同方 → 下级 → 他评（综合）
```

#### 3.2.3 他评计算方法

```
他评得分 = MEAN(上级得分, 协同方得分, 下级得分)
```

- 排除 NaN 来源后计算均值
- 如所有来源均为 NaN，则该维度他评 = NaN
- 不要求所有来源都有数据

#### 3.2.4 关系映射

| 原始值 | 输出值 |
|--------|--------|
| 自己 | 本人 |
| 上级 | 上级 |
| 下级 | 下级 |
| 协同方 | 协同方 |

## 4. 分析方法

### 4.1 描述性统计

#### 4.1.1 人口学统计

- 连续变量：均值、标准差、百分位数(P25/P50/P75)、范围
- 类别变量：频数、百分比
- 司龄分组：[0-3年)、[3-7年)、[7年以上)

#### 4.1.2 评分统计

- 按评价源 × 维度输出：N, M, SD, P25, P50, P75, Min, Max
- 评价源对比矩阵（均值表）
- 自评-他评差距分析：
  - 差距 = 自评均值 - 他评均值
  - 差距SD = 配对差距的标准差
  - Cohen's d = 差距均值 / 合并标准差

## 5. 质量控制

### 5.1 数据清洗检查点

| 检查项 | 方法 | 标准 |
|--------|------|------|
| 缺失模式 | 逐行统计非空条目数 | 仅允许全行缺失或固定模式缺失 |
| 评分范围 | 检查Min/Max | 1~5 Likert |
| 维度聚合前 | 计算Cronbach α | ≥ 0.70（规划） |
| 常模计算前 | Levene方差齐性检验 | 用于分组比较前提检验 |

### 5.2 版本管理

- 数据文件使用 `_rev` 后缀标识修正版本
- 处理脚本通过 git 版本控制
- 输出文件命名规则：`leadership_feedback_{level}_[type].csv`

### 7.2 评分量表

- 类型：Likert 5点量表
- 范围：1~5
- 含义：1=远低于期望，3=符合期望，5=远超期望

### 7.3 评价源说明

| 来源 | 含义 | 通常在... |
|------|------|----------|
| 本人 | 被评价人自评 | 所有维度均有评分 |
| 上级 | 被评价人的直接上级 | 所有维度均有评分 |
| 协同方 | 跨部门协作同事 | 不评价数智变革和发展组织 |
| 下级 | 被评价人的直接下属 | 所有维度均有评分 |
